Hull Tactical Research Pipeline

causal data → shared features/allocation → GBDT research → frozen evaluation → live artifacts

Leakage boundary

  • • train_end < prediction date
  • • pending targets never filled
  • • feature schema and scaler fitted before scoring
  • • holdout read once, after pre-registration

Evidence ladder

  • • replay → six-fold CV → deployment replay
  • • official 137-day window → attribution
  • • locked 95-day post-window
  • • HAC + block bootstrap + Holm, never raw Sharpe alone

Release gate

  • • tests and compile audit green
  • • data hashes and manifests recorded
  • • limitations disclosed, not hidden
  • • no holdout-driven model or multiplier selection
