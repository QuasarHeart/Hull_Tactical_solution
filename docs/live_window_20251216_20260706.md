# Official live forecasting window: 2025-12-16 to 2026-07-06

> **Extended:** the official competition end was moved slightly to
> **2026-07-06**. The extended 137-day result is appended at the bottom under
> "Extension to 2026-07-06"; the original 131-day result is retained below.

## Correction

The previous 2026-06-25 to 2026-07-06 calculation was based on a misread
window. The official Hull Tactical timeline is:

- Final submission deadline: **2025-12-15** (11:59 PM UTC)
- Forecasting begins after that deadline: **2025-12-16**
- Competition end date: **2026-06-25**

That gives **131 trading days** in the live panel. E14 is missing for the final
7 days of the window (2026-06-16 through 2026-06-25); the production median fill
is used for those days.

## Method

`scripts/score_live_window.py` was run from 2025-12-16 through 2026-06-25 with
four model protocols:

- **Daily Retrain**: dynamic builder + full daily retrain (current deployment,
  Phase 3 D);
- **Fixed builder + rolling**: one builder fitted at the start, model updated
  daily (Phase 4 B);
- **Offline**: fixed builder + fixed model, fitted once before the window
  (closest to a frozen submitted notebook);
- **Vol-only / Buy & Hold / Constant 1.25** as controls.

Training uses only `date_id < t` rows with realized targets; the target for
`t` is used only after the prediction for `t` is written. The first live day is
2025-12-16, so the model was trained on data through 2025-12-15 before the
window.

## Score caveat

The official scoring notebook `docs/reference/hull-competition-sharpe.ipynb` was executed
against the saved positions. It needs `forward_returns` and `risk_free_rate`;
the live source supplies neither, so the reconstructed inputs are:

```
fwd = target_metric + rf
rf  = 0
```

The notebook returns exactly the same numbers as `common.metrics.official_score`
(Daily Retrain **2.1921191431873206**). Adding a constant risk-free rate does
not change the score (the strategy and market return series both shift by the
constant), so the missing daily risk-free series is a very small approximation,
not a change in the metric. A true leaderboard score could still differ by a
small amount if the hidden daily risk-free series varies.

The score numerator and return-penalty term depend only on `target_metric` and
are exact; the volatility denominators would change slightly if the hidden
risk-free series were known. This is an **official-formula score on
reconstructed inputs**, not a guarantee of the Kaggle leaderboard value. In this
window both the volatility and return penalties are 1.0, so the official-style
score equals the raw Sharpe to the precision shown.

## What this changes

This is the first live out-of-sample period in which the GBDT strategy clearly
beats the simple controls:

- Daily Retrain 2.148 vs Buy & Hold 0.860, Constant 1.25 0.803, Vol-only 0.843;
- cumulative +11.50% vs +6.36% for Buy & Hold, with a smaller drawdown
  (-4.01% vs -9.66%).

It does not overturn the six-fold statistical conclusion: 131 days is still one
realized regime, not a series of independent folds, and the earlier six-fold
paired CIs were inconclusive. It does mean the official live window is much
more favorable than the seven-day window calculated earlier.

The exact hidden leaderboard score can differ because `fwd/rf` are unavailable;
the proxy uses `rf=0`, and the volatility denominators are therefore
approximate. If you want, I can rerun with open/close or risk-free data if you
supply the official evaluation file.

The official notebook was executed on the full 137-day positions and returns
exactly these scores; no proxy-formula discrepancy was found.

The added six trading days (2026-06-26 through 2026-07-06) contributed:

- Daily Retrain: **+0.636%** cumulative return; the overall official score rose
  from 2.1482 to **2.1921**; maximum drawdown stayed at -4.01%;
- Buy & Hold: **+2.478%** cumulative return over the same six days;
- Constant 1.25: **+3.100%** cumulative return.

The extra days did not change the qualitative conclusion: the model remains
ahead of the simple controls over the official live window, but the extension
is a short, strong-market segment and is not independent evidence.
